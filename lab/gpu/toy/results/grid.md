# Step 7: grid:K timing

Generated by `lab/gpu/toy/grid.py` (msvc twins; 300 ticks, the costs averaged per tick over ticks 2 to 300: tick 1 warms the drivers up). grid:K is K copies of pile200 (the same draws: 200 bodies falling into a pit) 6.5 m apart on one floor, sleep off, so every body is solved every tick. Cost only (NOTES.md, step 7).

Reproduce (Windows, from the repository's root):

```
python lab/gpu/toy/gen_toy.py && python lab/gpu/lab.py build --compiler msvc
python lab/gpu/toy/grid.py --ticks 300      # logs in lab/gpu/build/toy-scratch/grid
```

## Per tick (ms)

wall: the tick end to end (the GPUs: two submits, the readbacks, the CPU stages; the twin: its dispatches and stages); kernels: the dispatches' sum (GPUs: timestamps after every dispatch, each followed by a full barrier); cpu: the CPU stages (broadphase, islands, colouring, the lists); up/read: the GPUs' uploads before the dispatches and readbacks after them, from timestamps; then the kernels by stage, and the solve's cost per colour dispatch (warm start, push and relax: one dispatch per colour per substep).
